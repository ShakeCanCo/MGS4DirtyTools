# MGS4DirtyTools
A growing toolset for the MGS Master Collection Vol. 2. Currently working on Metal Gear Solid 4: Guns of the Patriots.

First of all, thanks for testing! It means a great deal.

So far, this tool will let you do the following things:

1. Level Select
2. Launcher Skip
3. Easy Setup - Due to popular demand, I've included a simple method to find your Steam MGS Installation
4. Create Custom Camos - Now with Normal Map Override!
5. Import your very own Custom Soundtrack - Now with Click & Drag functionality.
6. (Experimental) iPod Music Effects - Listen to Songs and have different in-game effects. Max Ammo is implemented, with more coming with upcoming updates.
7. (Experimental) Replace sound effects, voice overs and in-game BGM. Track Lengths aren't currently adjustable. Will be coming in a later update
8. Unlock all in-game soundtracks with the press of a button
9. Import / Export Textures - PNG/DDS/TGA with a bunch of import/export improvements.
10. Easy access to Video files with ability to easily replace with other .bk2 files (Note: You will need to install the Bink RAD Video Tools https://www.radgametools.com/bnkdown.htm)
   
With a roadmap to add so much more - All in one tool.
