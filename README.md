# MGS4DirtyTools  
A growing toolkit for the MGS Master Collection Vol. 2. Currently focus: **Metal Gear Solid 4: Guns of the Patriots.**  

Keep in mind that this tool is very much a Work in Progress, so hence the name.. It is very dirty!  
If you have suggestions or bugs, please reach out!  


Video: https://www.youtube.com/watch?v=r3G6eL-y5i0

What can you do with MGS4 Dirty Tools:  

1. **Level Select**  
   Quickly jump to levels & cutscenes

2. **Launcher Skip**

3. (NEW v0.6) **Granular HUD Customisation** (WIP)

4. **Easy Setup**  
      Quickly find your MGS Installation.  

3. **NEW: 3D Model Export / Import:**  
      - View and quickly open up models in Blender: Make edits, and bring it back in-game in one go!  
      - (EXPERIMENTAL) Scan the game and find out which models are loaded in memory and in view  
      - _(Note: This is a new feature so bugs are likely present. Feedback is appreciated but not required)_  

4. **Create Custom Camos**  
      - Import your own custom images, apply special effects from other camos, tweak camo index ratings.   

6. **Custom Soundtrack (iPod) and "Healing Frequencies" (WIP)**  
      - Import up to (currently) 73 Audio Tracks.  
      - Unlock all in-game soundtracks with the press of a button  
      - (EXPERIMENTAL) "Healing Frequencies" - Set special effects to your tracks, listen in-game to activate!  
      (Note: Max Ammo is implemented, with more coming with upcoming updates).  

7. **Custom Sound Effects (EXPERIMENTAL)**  
      - Replace sound effects, voice overs and in-game BGM.
      - Round trip audio files directly to and from Audacity from within MGS4DT (installation of Audacity required)  
      (Note: Track Lengths aren't currently adjustable. Will be coming in a later update.)  

8. **Custom Textures**  
      - Import / Export Textures: PNG/DDS/TGA.  
      - **UPDATE 0.5:** You can also see how textures affect certain models (experimental/non-comprehensive - Can also be achieved using the **model viewer**)
      - **UPDATE V0.6** Increased the available textures - Also has NPOT support. 

9. **Video**  
      - Easy access to Video files with ability to easily replace with other .bk2 files  
      (Note: You will need to install the Bink RAD Video Tools https://www.radgametools.com/bnkdown.htm)  

11. **EZ Updater**  
       - Check for updates directly from the application  
   
With a roadmap to add so much more - Thank you all for your support!
