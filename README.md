# MGS4DirtyTools  
A growing toolkit for the MGS Master Collection Vol. 2. Currently focus: **Metal Gear Solid 4: Guns of the Patriots.**  

Keep in mind that this tool is very much a Work in Progress, so hence the name.. It is very dirty!  
If you have suggestions or bugs, please reach out!  

LATEST VERSION: 0.6a - Either download from Releases or update directly from the application.

Latest Showcase Video: https://www.youtube.com/watch?v=r3G6eL-y5i0

What can you do with MGS4 Dirty Tools:  

1. **Level Select & Launcher Skip**  
   - Option to Skip the launcher
   - Quickly jump to levels & cutscenes
   - ***New: 0.6a*** Apply your own name tags and favourites to Levels. Helps with personal categorising

2. ***(NEW v0.6)*** **Granular HUD Customisation**  
   - Rearrange. Change and Remove HUD elements
   - Tweak and change the Weapon / Item selection menu animations to a number of different options: Straight, Arc
   - Change HUD text i.e. OLD SNAKE, PSYCHE, ALERT and more
   - Change the LIFE / Psyche Bar to one of the following health bars inspired by previous Metal Gear games:
   MGS1, MGS2, MGS3, Peace Walker, Peace Walker (Boss Inspired), Portable Ops and a minimalist 
   - ***(0.6a)*** Themed Radars after Classic Metal Gear and Peace Walker.
   - ***(0.6a)*** Change the Weapon / Item Select to a Peace Walker inspired menu (Will require Dirty Tools to be open in the background to work properly due to requiring OTF memory patching)
   - ***(0.6a)*** Hide the Stage Transition bars and text
   - ***(0.6a)*** **(EXPERIMENTAL)** Custom Fonts
   - Export / Import Custom HUDs
  
3. ***(NEW 0.6a)*** Real-Time Tweaks
   - iPod Background Playback: Listen to the iPod uninterrupted. **Hit Play and Equip any other items you desire!**
   - Passive Solid Eye Features - Scan Items, NPCs or both. It's granular - you can turn them on and off as you see fit.
   - Passive Radar
   - Threat Ring Removal (!)
   - Set your own custom activation / deactivation sfx

5. **Easy Setup**  
    - Quickly find your MGS Installation (Windows only).  

6. **3D Model Export / Import:**  
      - View and quickly open up models in Blender: Make edits, and bring it back in-game in one go!  
      - (EXPERIMENTAL) Scan the game and find out which models are loaded in memory and in view  
      - _(Note: This is a new feature so bugs are likely present. Feedback is appreciated but not required)_  

7. **Create Custom Camos**  
      - Import your own custom images
      - Apply special effects from other camos to your custom camo
      - Tweak camo index ratings (Experimental)   

8. **Custom Soundtrack (iPod) and "Healing Frequencies" (WIP)**  
      - ***NEW 0.6a*** Background Playback of iPod Tracks
      - Import up to (currently) 73 Audio Tracks.  
      - Unlock all in-game soundtracks with the press of a button  
      - (EXPERIMENTAL) "Healing Frequencies" - Set special effects to your tracks, listen in-game to activate!  
      (Note: Max Ammo is implemented, with more coming with upcoming updates).  

9. **Custom Sound Effects (EXPERIMENTAL)**  
      - Replace sound effects, voice overs and in-game BGM.
      - Round trip audio files directly to and from Audacity from within MGS4DT (installation of Audacity required)  
      (Note: Track Lengths aren't currently adjustable. Will be coming in a later update.)  

10. **Custom Textures**  
      - Import / Export Textures: PNG/DDS/TGA.  
      - **UPDATE 0.5:** You can also see how textures affect certain models (experimental/non-comprehensive - Can also be achieved using the **model viewer**)
      - **UPDATE V0.6** Increased the available textures - Also has NPOT support. 

11. **Video**  
      - Easy access to Video files with ability to easily replace with other .bk2 files  
      (Note: You will need to install the Bink RAD Video Tools https://www.radgametools.com/bnkdown.htm)  

12. **EZ Updater**  
       - Check for updates directly from the application  
   
With a roadmap to add so much more - Thank you all for your support!
